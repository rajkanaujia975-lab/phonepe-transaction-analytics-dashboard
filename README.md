Project Overview

This Power BI dashboard analyzes PhonePe transaction data to identify transaction trends, payment patterns, and business insights.

Key Metrics

- Total Transactions
- Total Transaction Amount
- Registered Users
- Transaction Success Rate
- Average Transaction Value
- Year-over-Year Growth

Tools Used

- Power BI
- DAX
- Excel
- Data Analysis
- Data Visualization

Insights Generated

- State-wise transaction performance
- Transaction type analysis
- User growth trends
- Payment success analysis
- Business performance tracking
