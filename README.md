# phonepe-transaction-analytics-dashboard

Data analytics project using Power BI to visualize PhonePe transactions, identify payment trends, and generate actionable business insights.
Dashboard Preview

https://github.com/rajkanaujia975-lab/phonepe-transaction-analytics-dashboard/blob/main/phonepe%20yearly%20data%20analysis.png%20(2).png

Project Overview

This Power BI dashboard analyzes PhonePe transaction data to identify transaction trends, payment patterns, and business insights.

Key Metrics

- Total Transactions
- Total Transaction Amount
- unique Users
- Transaction Success Rate
- Average Transaction Value
- Year-over-Year Growth

Tools Used

- Power BI
- DAX
- Excel
- Data Analysis
- Data Visualization

Insights Generated

- State-wise transaction performance
- Transaction type analysis
- User growth trends
- Payment success analysis
- Business performance tracking
